# GYM

App Android personale per la palestra: schede, circuiti da un'ora, allenatore che propone gli esercizi, libreria con muscoli e video, progressi, promemoria.

- **Scaricare l'app:** sezione [Releases](../../releases) → ultimo file `GYM-1.0.x.apk`.
- **Aggiornare:** dall'app, Impostazioni → Aggiornamenti → *Controlla aggiornamenti*. L'app avvisa anche da sola all'avvio.
- Ogni modifica sul ramo `main` genera automaticamente una nuova versione (GitHub Actions).

Specifica completa: [SPEC.md](SPEC.md).
