# Coach

App Android personale: il "cervello" che sta dietro a **Hevy**. Coach prepara il percorso su misura, le schede con i carichi di oggi, la valutazione di ogni seduta, i traguardi e l'alimentazione; ti alleni e registri in Hevy.

- **Collegamento:** Impostazioni → Hevy → incolla la chiave API (hevy.com → Settings → Developer, serve Hevy Pro).
- **Health Connect** (facoltativo): passi, sonno e peso da telefono, orologio o bilancia.
- **Scaricare l'app:** sezione [Releases](../../releases). Aggiornare: Impostazioni → Aggiornamenti.
